# Архитектурные решения

## 2024-XX-XX — InvalidCastException в BoardView
**Проблема:** Массив `GemView[,]` меняет размер после инициализации, вызывая `InvalidCastException` при кастинге.  
**Решение:** Замена на `List<GemView>` для динамического размера.  
**Причина:** Unity не поддерживает изменение размера массива в runtime без создания нового массива.  
**Альтернативы:** Использовать `[,]` с правильным размером сразу (не применимо, так как размер известен только после Init).

## 2024-XX-XX — Синтаксические ошибки в LevelService.cs
**Проблема:** Тернарный оператор внутри string interpolation и использование LINQ методов на массивах Unity.  
**Решение:** Вынес тернарное выражение в переменную, замена `.Sum()` на `.Cast().Where().Count()`.  
**Причина:** LINQ методы не работают напрямую на массивах Unity без `using System.Linq;`.

## 2024-XX-XX — Добавление CellSize в BoardConfig
**Проблема:** Отсутствует свойство `CellSize` в конфигурации доски.  
**Решение:** Добавлено `public float CellSize { get; private set; } = 64f;`.  
**Причина:** Необходим для расчёта размеров ячеек в UI.
