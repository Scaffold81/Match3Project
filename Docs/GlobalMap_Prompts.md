# GlobalMap — Промпты для разработки и графики

> Концепция: вертикальный ScrollRect. Карта — набор секций (по одной на страну),
> стыкующихся через отдельный Transition-спрайт между каждой парой стран.
> Добавить новую страну = добавить секцию + один transition-спрайт.

---

## 📐 Промпт для разработки (техническое задание)

```
Задача: Спроектировать экран StageMap с бесконечно расширяемой вертикальной картой
для мобильной Match-3 игры Lost Expedition.

## Концепция карты
Вертикальный ScrollRect. Content собирается динамически из секций:

  [CountrySectionView — Египет        ]  ← спрайт секции egypt_map.png
  [CountryTransitionView — Египет→Греция] ← спрайт перехода transition_egypt_greece.png
  [CountrySectionView — Греция        ]  ← спрайт секции greece_map.png
  [CountryTransitionView — Греция→Китай]  ← спрайт перехода transition_greece_china.png
  ...и так далее

Добавить новую страну = добавить CountryConfig + два спрайта (секция + переход к следующей).

## Архитектура

### CountryMapConfig (ScriptableObject, расширяет CountryConfig)
  SectionSprite    : Sprite   — фоновый спрайт секции этой страны (390×1400px)
  SectionHeight    : float    — высота секции в пикселях (default: 1400)

### CountryTransitionConfig (ScriptableObject)
  menuName: "Match3/Configs/CountryTransition"
  FromCountryIndex : int
  ToCountryIndex   : int
  TransitionSprite : Sprite   — спрайт перехода (390×300px)
  TransitionHeight : float    — высота перехода (default: 300)

### WorldMapConfig (обновить)
  Countries[]    : CountryConfig[]           — секции стран
  Transitions[]  : CountryTransitionConfig[] — переходы между странами

### CountrySectionView (MonoBehaviour, Prefab)
  — Image для SectionSprite (растягивается по высоте секции)
  — RectTransform.sizeDelta.y = SectionHeight из конфига
  — содержит StageNodeView[] и CountryNodeView — как сейчас

### CountryTransitionView (MonoBehaviour, Prefab)
  — Image для TransitionSprite
  — RectTransform.sizeDelta.y = TransitionHeight из конфига
  — не содержит игровых узлов

### StageMapView (обновить)
  BuildContent(WorldMapConfig):
    for i in 0..Countries.Length:
      Instantiate(CountrySectionPrefab) → Setup(Countries[i])
      if i < Countries.Length - 1:
        Instantiate(CountryTransitionPrefab) → Setup(Transitions[i])

  — Content высота = сумма всех SectionHeight + TransitionHeight
  — _placeNodes, _clearNodes — оставить для Editor-режима

## Что НЕ меняется
  — StageNodeView, CountryNodeView — без изменений
  — StageMapPresenter — без изменений
  — ProgressService — без изменений

## TODO после реализации
  — Обновить WorldMapConfig: добавить Transitions[]
  — Обновить StageMapUISetup (Editor): генерировать секции + переходы
  — Создать Prefab CountrySectionView и CountryTransitionView
  — Заказать/сгенерировать спрайты (промпты ниже)
```

```
Нарисуй фоновый спрайт секции карты для страны "Египет" в мобильной match-3 игре
про археолога. Это вертикальная полоса фона, на которой располагаются узлы уровней.

Технические требования:
— Размер: 390×1400px, вертикальный
— Формат: PNG с прозрачностью по краям (верх и низ — плавный fade to transparent ~150px)
— Верхний и нижний край: плавный градиент в прозрачность для стыковки с соседними секциями

Визуальное содержимое (фон, не UI):
— Пустынный пейзаж Египта: барханы, силуэты пирамид вдалеке
— Детали раскопа: деревянные подпорки, верёвки, слои грунта по бокам
— Декоративные элементы вдоль краёв: иероглифы, египетские орнаменты, папирус
— Общее ощущение: "мы копаем вглубь египетских песков"

Цветовая палитра:
— Тёплые тона: золотистый песок (#D4C5A0), терракота (#C96442), охра (#C8860A)
— Тёмный фон для контраста с UI-элементами поверх
— Ночная или закатная атмосфера (легче читать UI элементы поверх)

Важно:
— Центральная область (300px по ширине) — достаточно тёмная и нейтральная,
  чтобы поверх хорошо читались круглые кнопки узлов и пунктирная дорожка
```
