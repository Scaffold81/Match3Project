## 💡 Советы по использованию промптов

- **ChatGPT (GPT-4o):** вставляй промпт целиком, попроси нарисовать через DALL-E.
- **Алиса / YandexGPT:** используй только текстовое описание для составления ТЗ дизайнеру.
- **Midjourney:** убери лишние технические детали, добавь `--ar 9:16 --style raw`.
- **Figma AI / Adobe Firefly:** указывай стиль "mobile UI wireframe, warm tones, archaeology theme".

Для каждого экрана можно сначала попросить **wireframe** (схему с блоками), а потом отдельно **стилизованный mockup** с реальными цветами.
