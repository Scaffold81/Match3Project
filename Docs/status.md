1. Открой Unity → переключись в Play Mode (зелёная кнопка)
2. **Ожидание:** должно появиться рандомное поле 5×7 с фишками всех типов
3. Если поле всё ещё пустое или есть ошибки — проверь консоль (`Window → General → Console`)
