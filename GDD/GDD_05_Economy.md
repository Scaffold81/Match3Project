## 💰 Валюты

### Монеты (Coins)
| Параметр | Значение |
|----------|---------|
| Хранение | `WalletService` → PlayerPrefs `"wallet_coins"` |
| Начальный баланс | 500 монет |
| Максимум | Без ограничений |
| Отображение | `WalletView` — в HUD и в метах |

### Жизни (Lives)
| Параметр | Значение |
|----------|---------|
| Хранение | `WalletService` → PlayerPrefs `"wallet_lives"` |
| Максимум | 5 жизней |
| Восстановление | 1 жизнь / 30 минут (таймер) |
| Старт | 5 жизней |
| Расход | 1 жизнь за поражение |
| Пополнение платно | 5 жизней за N монет / IAP |

> Реализация таймера восстановления — Фаза 3.

## 🎒 Инвентарь бустов (InventoryService)

Хранится в PlayerPrefs: `"inventory_{boostType}"` — количество штук.

| BoostType | Ключ | Начальное количество |
|-----------|------|---------------------|
| HorizontalArrow | `inventory_HorizontalArrow` | 1 |
| VerticalArrow | `inventory_VerticalArrow` | 1 |
| ColorBomb | `inventory_ColorBomb` | 0 |
| Bomb | `inventory_Bomb` | 1 |
| MegaBomb | `inventory_MegaBomb` | 0 |
| Hint | `inventory_Hint` | 3 |
| Shuffle | `inventory_Shuffle` | 2 |

**Механика расхода:**
- Буст списывается в момент применения (`TryConsume`)
- Если `Count == 0` → кнопка заблокирована, тап → попап покупки

## 🎁 Система наград (RewardService)

### Типы наград (RewardType)

| RewardType | Что выдаётся |
|-----------|-------------|
| `Coins` | `WalletService.AddCoins(amount)` |
| `Lives` | `WalletService.AddLives(amount)` |
| `Boost` | `InventoryService.AddBoost(type, amount)` |
| `SuperPrize` | Открытие следующей страны + специальная анимация |

### Где выдаются награды

| Источник | Награда |
|----------|---------|
| Первое прохождение этапа | `StageConfig.StageRewards[]` (один раз) |
| Бонусный этап | `SuperPrize` + монеты + бусты |
| Ежедневный бонус | Монеты / бусты (Фаза 3) |
| Реклама (Rewarded) | +5 жизней / буст / монеты (Фаза 3) |
| IAP (Магазин) | Пакеты монет / бустов (Фаза 4) |

### Поток StageRewardPopup
```
RewardService.GrantAll(rewards)
  → WalletService / InventoryService обновлены
  → StageRewardPopupView.Show(rewards) — анимация получения
  → Игрок тапает Claim → PopupPresenter.OnClaimClicked()
  → LoadScene(StageMap)
```

## 📊 Баланс монет — ожидаемый поток

| Источник | Монеты/неделю |
|----------|--------------|
| Этапы (первое прохождение) | 700–1500 |
| Ежедневные бонусы × 7 | 350–700 |
| Rewarded Ads × 14 | 280–560 |
| **Итого приход** | ~1300–2700 |

| Расход | Монеты/неделю |
|--------|--------------|
| Бусты (3–5 за сессию, 7 дней) | 1000–2500 |
| Жизни (4–6 раз) | 800–1200 |
| **Итого расход** | ~1800–3700 |

**Дефицит ~1000 монет/неделю** → органическая мотивация к покупке.

## 📺 Рекламные механики (Фаза 3)

| Момент показа | Формат | Награда |
|---------------|--------|---------|
| После поражения | Rewarded | +5 ходов (second chance) |
| В метагейме | Rewarded | +3 жизни или буст |
| Между сессиями | Interstitial | — (без награды) |
| В магазине | Rewarded | 2× монеты пакета |

**Частота Interstitial:** не чаще 1 раза в 3 минуты, не показывать после победы.
