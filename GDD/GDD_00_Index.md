## 🎯 Одна строка о проекте

**Lost Expedition** — казуальный Match-3 пазл, где игрок-археолог путешествует по миру, раскапывая артефакты утерянных цивилизаций.

---

## 🔑 Ключевые параметры

| Параметр | Значение |
|----------|---------|
| Жанр | Match-3 Puzzle (Casual) |
| Платформа | Mobile — Android / iOS |
| Сессия | 2–5 минут на уровень |
| Аудитория | Casual, 12+, преимущественно 25–45 лет |
| Монетизация | F2P: IAP + Rewarded Ads |
| Уровней к релизу | ≥ 50 (план: 135+) |
| Стран / Глав | 5 (план: 7+) |
