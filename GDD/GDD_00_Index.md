## 🎯 Одна строка о проекте

**Lost Expedition** — казуальный Match-3 пазл, где игрок-археолог путешествует по миру, раскапывая артефакты утерянных цивилизаций.

## ⚡ Важные архитектурные факты (чтобы не путаться)

| Факт | Описание |
|------|---------|
| **Экрана победы нет** | Победа внутри этапа = мгновенный переход на следующий уровень. Звёзды сохраняются тихо |
| **Победа на последнем уровне** | → `StageRewardPopupView` с наградами → карта |
| **Поражение** | → `LevelResultView` с персонажем (`SadCharacterSprite`) и счётчиком жизней |
| **Жизни** | `LivesService` — отдельный сервис, не `WalletService` |
| **Монеты** | `CoinService` — отдельный сервис |
| **CountryCompletePopupView** | Показывается на StageMap, не в игровой сцене |
| **EnableInput** | Ввод включается только после закрытия `LevelTaskPopupView` |
