## 🗺️ Иерархия контента

```
WorldMapConfig
 └── CountryConfig[6]          — 6 стран (глав)
       └── StageConfig[10]     — 9 обычных этапов + 1 бонусный
             ├── IsBonusStage  — индекс 9 — бонусный, даёт SuperPrize
             └── LevelConfig[3]— 3 уровня на этап

Итого уровней: 6 × 9 × 3 = 162 обычных + 6 бонусных = 168
```

## 🏅 Этапы (StageConfig)

Каждый этап содержит **3 уровня** + **StageRewards[]** (награды за первое прохождение).

### Разблокировка этапов
```
Этап 0, Страна 0        → всегда открыт
Этап N > 0              → открывается когда этап N-1 завершён
Этап 0, Страна M > 0    → открывается когда бонусный этап страны M-1 завершён
Бонусный этап (индекс 9) → открывается когда ВСЕ 9 обычных этапов страны завершены
```

### Бонусный этап
- Последний этап каждой страны (индекс 9)
- Уникальный визуал — Boss-уровень
- Открытие артефакта цивилизации (кат-сцена)
- Выдаёт **SuperPrize** через `RewardService`
- Открывает следующую страну на карте

## 📐 Формы досок

Форма задаётся через `CellType.Hidden` в `LevelConfig.Grid[]`.

### FULL 7×7
Все ячейки Normal. Стандартное поле.

### ROUNDED 7×7
```
H . N N N N N . H
N N N N N N N N N   ← ×5 строк
H . N N N N N . H
```
Срезанные углы (2×2).

### CROSS 7×7
```
H H N N N H H
H H N N N H H
N N N N N N N   ← ×3 строки
H H N N N H H
H H N N N H H
```
Скрыты 2×2 угловые блоки.

### DIAMOND 7×7
```
H H H N H H H
H H N N N H H
H N N N N N H
N N N N N N N
H N N N N N H
H H N N N H H
H H H N H H H
```
Ромбовидная форма.

### HOURGLASS 7×7
```
N N N N N N N
H N N N N N H
H H N N N H H
H H H N H H H
H H N N N H H
H N N N N N H
N N N N N N N
```
Форма песочных часов.

### STAIRS 8×7
```
N N N N N N N
. N N N N N N
. N N N N N N
. . N N N N N
. . N N N N N
. . . N N N N
. . . N N N N
. . . . N N N
```
Лестница (левый нижний угол заполнен Hidden).

### T-SHAPE 8×8
```
N N N N N N N N   ← ×2 верхних строки
H H N N N N H H
H H H N N H H H   ← ×5 строк ствола
...
```

## 🧱 Конфигурация препятствий в уровне (YAML-формат)

```yaml

# cellType:     0=Normal 1=Hidden
# obstacleHp:   0 = дефолт для типа

grid:
  - row: 3
    col: 3
    cellType: 0
    obstacleType: 1   # Ice
    obstacleHp: 2
```
