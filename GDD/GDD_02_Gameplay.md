# GDD 02 — Геймплей

---

## 🔄 Базовый игровой цикл

```
Старт уровня
  → Попап задания (LevelTaskPopupView)
  → Игрок нажимает Play
  → Игровое поле активно

Игрок делает ход (Swap)
  → Матч найден → Уничтожение фишек
     → Регистрация прогресса цели
     → Удар по препятствиям
     → Гравитация (падение фишек)
     → Спаун новых фишек сверху
     → Каскадная проверка матчей (без хода)
  → Матч не найден → анимация отказа

Проверка условий после каждого хода:
  → Победа: все цели выполнены
  → Поражение: ходы закончились

Победа → Расчёт звёзд → Сохранение → Следующий уровень / карта
Поражение → LevelResultView → Рестарт / Назад на карту
```

---

## 🔀 Своп (Swap)

- Игрок касается **двух соседних фишек** (горизонталь или вертикаль)
- Своп разрешён **только если даёт ≥ 1 матч**
- Если матча нет → фишки возвращаются с анимацией отказа (тряска)
- Диагональный своп — **запрещён**
- Суперфишки при свопе с обычной → активируют своё действие
- Суперфишки при свопе **между собой** → комбо-эффект (TODO: Фаза 3)

## 🧩 Типы ячеек (CellType)

| Тип | Поведение |
|-----|-----------|
| `Normal` | Стандартная ячейка, содержит фишку |
| `Hidden` | Пустое место — нет фишки, не участвует в матчах, не блокирует (форма доски) |

**Начальное заполнение:**
- `Normal` + `NodeType.None` → случайная фишка из `AllowedNodeTypes[]`
- `Normal` + конкретный тип → фишка заданного типа
- `Hidden` → пусто навсегда

| Тип цели | Нарратив | Описание |
|----------|----------|---------|
| **Collect** | Собери артефакты | Собрать N фишек указанного типа |

| **Collect + ClearLayer** | Комплексная задача | Обе цели одновременно |

## ⚙️ Матч (Match)

- Засчитывается **3 и более** одинаковых фишек в ряд **или** столбец
- Т-образные и Г-образные пересечения = **один матч** (все участвующие ячейки уничтожаются)
- Фишки уничтожаются **одновременно** с анимацией

### Особые матчи → Суперфишки

| Паттерн | Создаётся | Размещение |
|---------|-----------|-----------|
| 4 в ряд (горизонталь) | `HorizontalArrow` | На месте свопнутой фишки |
| 4 в ряд (вертикаль) | `VerticalArrow` | На месте свопнутой фишки |
| 5 в прямую | `ColorBomb` | На месте свопнутой фишки |
| Т / Л форма (5 клеток) | `Bomb` | В центре фигуры |
| 6+ или крест | `MegaBomb` | В центре фигуры |

## 💥 Суперфишки (SuperGemType)

| Суперфишка | Нарратив | Эффект |
|-----------|----------|--------|
| `HorizontalArrow` | **Кисть** — широкий мазок | Уничтожает весь ряд |
| `VerticalArrow` | **Скребок** — вертикальный прорез | Уничтожает весь столбец |
| `ColorBomb` | **Амулет** — притягивает подобное | Уничтожает все фишки одного цвета |
| `Bomb` | **Лопата** — точный удар | Взрыв 3×3 |
| `MegaBomb` | **Динамит** — направленный подрыв | Взрыв 5×5 |

## ⬇️ Гравитация и Спаун

**Гравитация:**
- После уничтожения фишек — фишки **падают вниз**, заполняя пустоты
- Анимация: плавное падение с отскоком (DOTween OutBounce)
- Препятствия типа `Box` и `Rock` **блокируют** падение

**Спаун:**
- Новые фишки появляются **сверху** каждого доступного столбца
- Тип — случайный из `AllowedNodeTypes[]` текущего уровня
- Анимация: фишка влетает сверху (как сыплется земля)

**Каскад:**
- После гравитации + спауна → автопроверка новых матчей
- Не тратит ход, не ограничен
- Визуально: нарастающий эффект (каждый каскад ярче/громче)

## 🏔️ Препятствия (Obstacle System)

Препятствия хранятся в `BoardCell` (ObstacleType + ObstacleHp).

| Тип | Нарратив | HP | Триггер удара | Блокирует падение |
|-----|----------|----|---------------|-----------------|
| `Ice` | Замёрзший грунт | 1–2 | Смежный матч | Нет (фишка внутри) |
| `Box` | Твёрдый ящик / камень | 1–3 | Смежный матч | **Да** |
| `Chain` | Цепи вокруг фишки | 1–2 | HP=1: прямой матч; HP>1: смежный | Нет |
| `Rock` | Монолитная скала | 2–4 | Смежный матч | **Да** |

**Логика ударов:**
- `ProcessObstaclesFromMatch(matchedCells)` — обрабатывает смежные удары по правилам каждого типа
- `HitObstaclesDirectly(cells)` — прямой удар (бусты, суперфишки)
- При снятии всех HP → `OnObstacleCleared`
- При очистке всей доски → `OnAllObstaclesCleared` → проверка победы

## 🧰 Бусты (BoostType)

Хранятся в `InventoryService` (PlayerPrefs). Применяются **во время уровня** из рюкзака.

| BoostType | Нарратив | Эффект |
|-----------|----------|--------|
| `HorizontalArrow` | **Кисть** | Уничтожает весь ряд |
| `VerticalArrow` | **Скребок** | Уничтожает весь столбец |
| `ColorBomb` | **Амулет** | Уничтожает все фишки одного цвета |
| `Bomb` | **Лопата** | Взрыв 3×3 |
| `MegaBomb` | **Динамит** | Взрыв 5×5 |
| `Hint` | **Лупа** | Подсвечивает лучший возможный ход |
| `Shuffle` | **Встряска** | Перемешивает все фишки на доске |

**Поток применения:**
1. Игрок тапает иконку в `BackpackView` → `BoostService.SelectBoost()`
2. `SwapService.ClearSelection()` — сброс выбранной фишки
3. Игрок тапает по ячейке на поле → `BoostService.TryApplyBoostAt()`
4. `GameLoopController.ApplyBoostAtAsync()` → эффект + `ProcessTurnResult()`

## 🔢 Ограничения уровня

| Параметр | Описание |
|----------|---------|
| `MoveLimit` | Макс. ходов. `0` = без ограничений |
| `AllowedNodeTypes[]` | Типы фишек на уровне (3–6 цветов) |

- **Победа:** все цели выполнены ≤ MoveLimit ходов
- **Поражение:** ходы закончились, ≥ 1 цель не выполнена
