## ⭐ Система звёзд

Звёзды начисляются на основе оставшихся ходов после победы.

| Звёзды | Условие |
|--------|---------|
| ⭐ | Уровень пройден (любой остаток ходов ≥ 0) |
| ⭐⭐ | Пройдено с ≥ 30% оставшихся ходов |
| ⭐⭐⭐ | Пройдено с ≥ 60% оставшихся ходов |

**Пример:** MoveLimit = 30, осталось 20 ходов → 20/30 = 66% → ⭐⭐⭐

**Реализация:** `StarCalculator.Calculate(movesLeft, moveLimit)`

### Хранение звёзд
```
PlayerPrefs: "progress_stars_{countryIndex}_{stageIndex}_{levelIndex}"
Сохраняется лучший результат (SetStars только если новее > старого)
```

### Агрегация
- `GetStageStars(c, s)` → сумма 0–9 (3 уровня × 3 звезды)
- `GetCountryStars(c)` → сумма по 9 обычным этапам (0–81)
- Бонусный этап в счёт страны **не включается**

## 🗺️ Карта уровней (StageMap)

### Визуальная структура
- Вертикальный скролл-список `ScrollRect`
- Зигзаг-расположение узлов (чередование лево/право)
- 50 объектов в Content (5 `CountryNodeView` + 45 `StageNodeView`)

### StageNodeView (кнопка этапа, 90×80px)
| Состояние | Визуал |
|-----------|--------|
| Locked | Иконка замка, серый цвет |
| Unlocked | Яркая кнопка, счётчик звёзд |
| Bonus | Золотой цвет, специальная иконка |

### CountryNodeView (заголовок страны, 300×72px)
- Иконка страны + название + цвет секции
- Недоступная страна — серый/затемнённый

### Попап выбора уровня (LevelSelectPopupView)
- Название этапа
- 3 кнопки уровней (каждая показывает заработанные звёзды)
- Недоступные уровни — заблокированы
- Кнопка закрыть

---

## 🔓 Логика разблокировки

### Этапы
```
Этап [0] в стране [0]         → всегда открыт
Этап [N] в стране [C]         → IsStageCompleted(C, N-1) == true
Этап [0] в стране [C > 0]     → IsCountryCompleted(C-1) == true
Бонусный этап [9] в стране [C] → AreAllRegularStagesCompleted(C) == true
```

### Уровни внутри этапа
```
Уровень 0 → всегда открыт (если этап открыт)
Уровень 1 → уровень 0 пройден (≥1 звезда)
Уровень 2 → уровень 1 пройден (≥1 звезда)
```

### IsStageCompleted(c, s)
Все 3 уровня имеют ≥ 1 звезду.

### IsCountryCompleted(c)
Бонусный этап страны пройден.

## 🏆 Система завершения этапа

```
Последний уровень этапа пройден?
  wasStageCompleted (ДО SaveProgress) == false → ПЕРВОЕ прохождение
    → RewardService.GrantAll(stage.StageRewards)  ← награды только 1 раз
    → StageRewardPopupView.Show()
    → Игрок нажимает Claim
    → LoadScene(StageMap)

  wasStageCompleted == true → повторное прохождение
    → прямо на StageMap (без попапа наград)
```

## 🌟 Бонусный этап и SuperPrize

Условие открытия: все 9 обычных этапов страны завершены.

**SuperPrize содержит:**
- Крупная сумма монет
- Пакет редких бустов

## 📈 Кривая сложности

### Принципы
1. **Первые 2 этапа** каждой страны — обучение новой механики без стресса
2. **Середина (3–7 этапы)** — нарастание комбо препятствий
3. **Финал (8–9 этапы)** — максимальная сложность страны
4. **Бонусный** — пик страны, требует умения использовать бусты

### Инструменты сложности
| Инструмент | Эффект |
|-----------|--------|
| Уменьшение ходов | Прямое давление на игрока |
| Добавление цветов | Хаотичность доски, меньше совпадений |
| Сложные формы досок | Ограничение цепочек матчей |
| Комбо препятствий | Требует планирования |
| Увеличение размера | Больше переменных, дольше партия |

---

## 🔁 Повторное прохождение (Replay)

- Уже пройденный уровень можно перепройти
- Если получено больше звёзд — сохраняется лучший результат
- Повторные награды за этап **не выдаются** (проверка wasStageCompleted)
- Мотивация для реплея: улучшить звёзды, фарм монет (Фаза 4)
