# GDD 06 — UI / UX

---

## 🖥️ Экраны и навигация

```
[Boot]
  ↓ LoadScene
[StageMap]  ←──────────────────────────────────────────────┐
  ↓ Тап на этап                                             │
[LevelSelectPopup]                                          │
  ↓ Тап на уровень                                          │
[LoadScene(GamePlay)]                                       │
  ↓                                                         │
[GamePlay]                                                  │
  ├── LevelTaskPopupView (старт) → Play/Tap → игра активна  │
  │                                                         │
  ├── Победа (не последний уровень) → сразу LoadScene(Game) ┘
  │       ↑ без попапа, без анимации звёзд
  │
  ├── Победа (последний уровень этапа)
  │     → StageRewardPopupView.Show()
  │     → Claim → LoadScene(StageMap)
  │
  └── Поражение
        → LevelResultView.Show(SadCharacterSprite)
        → [Рестарт] → TrySpendLife() + LoadScene(Game)
        → [На карту] → LoadScene(StageMap)  ← жизнь НЕ тратится

[StageMap]
  └── Если PendingCountryReward → CountryCompletePopupView
        → Claim → карта (следующая страна открыта)
```

---

## ⚠️ Ключевые отличия от типичного Match-3

> **Отдельного экрана победы со звёздами — НЕТ.**
> Победа внутри этапа (не последний уровень) = мгновенный переход на следующий уровень.
> Победа на последнем уровне этапа = `StageRewardPopupView` с наградами.
> Звёзды сохраняются в `ProgressService` тихо, без показа.

## 📋 Попапы — детальное описание

---

### LevelTaskPopupView (старт уровня)

**Триггер:** `GameFlowService.ShowCurrentLevelTask()` при инициализации сцены  
**Закрытие:** кнопка Play **или** тап в любом месте попапа (`IPointerClickHandler`)  
**После закрытия:** `GameFlowService.StartPlay()` → `GameLoopController.EnableInput()`

```
┌─────────────────────────────────┐
│  [Персонаж (CharacterSprite)]   │
│                                 │
│  Stage 3 — Уровень 2            │
│                                 │
│  Цели:                          │
│  [ 🔵 иконка ]  Lapis ×25       │
│  [ ❄️ иконка ]  Лёд ×8          │
│                                 │
│       [ ▶ НАЧАТЬ ]              │
└─────────────────────────────────┘
```

**Данные из кода:**
- `levelTitle` = `"{stage.StageName} — Уровень {levelIndex + 1}"`
- `characterSprite` = `stage.CharacterSprite`
- Объективы: иконки из `GemConfig.GetVisual(nodeType).Sprite`

### LevelResultView — Поражение

**Триггер:** `gameFlowService.OnLevelLost` → `Show(stage.SadCharacterSprite)`  
**Жизни:** берётся из `LivesService.Lives` (не WalletService)

```
┌─────────────────────────────────┐
│  [Персонаж грустный             │
│   (SadCharacterSprite)]         │
│                                 │
│  "Не хватило ходов!"            │
│                                 │
│  Жизни: 3/5                     │
│                                 │
│  [ 🔄 Ещё раз ]  [ 🗺 На карту ]│
└─────────────────────────────────┘
```

**Логика кнопок:**
| Кнопка | Действие |
|--------|---------|
| Ещё раз | `LivesService.TrySpendLife()` → `LoadScene(Game)` |
| На карту | `LoadScene(StageMap)` — жизнь **не тратится** |

**Появление:** `CanvasGroup.DOFade(1f, 0.25f, Ease.OutQuad)` → затем `interactable = true`

---

### StageRewardPopupView (завершение этапа)

**Триггер:** `GameFlowService.HandleStageComplete()` — только если это последний уровень этапа  
**Победа внутри этапа (не последний уровень) = попапа НЕТ**

```
┌─────────────────────────────────┐
│  "Stage 3 — Этап завершён!"     │
│                                 │
│  [ 💰 иконка ] +200 монет       │
│  [ 🧰 иконка ] Кисть ×1         │
│  [ 🔍 иконка ] Лупа ×1          │
│                                 │
│         [ ПОЛУЧИТЬ ]            │
└─────────────────────────────────┘
```

**Данные из кода:**
- `titleText` = `"{stage.StageName} — Этап завершён!"`
- Иконки наград: `RewardIconConfig.GetIcon(reward.Type, reward.Boost)`
- `OnClaimClicked` → `GoToMap()` → `LoadScene(StageMap)`

**Важно:** Награды выдаются **ДО** показа попапа (`RewardService.GrantAll` в `HandleStageComplete`)

## 🎨 Визуальный фидбек

### Фишки
| Событие | Эффект |
|---------|--------|
| Выбор | Scale up + подсветка |
| Своп | DOTween Move |
| Отказ в свопе | DOTween Shake |
| Уничтожение | Scale → 0 + вспышка |
| Суперфишка создана | Пульсация + свечение |
| Подсказка (Hint) | `GemView.PlayHint()` — мигание |
| Падение | DOTween Move + OutBounce |

### Препятствия
| Событие | Эффект |
|---------|--------|
| Удар | Тряска + трещина на спрайте |
| Уничтожение | Разлёт осколков (VFX) |

### Каскад
| Уровень | Эффект |
|---------|--------|
| 1 | Обычная вспышка |
| 2 | "2x Combo!" + жёлтый блик |
| 3+ | "COMBO!" + оранжевый блик + сотрясение экрана |

### Объективы
| Событие | Эффект |
|---------|--------|
| Прогресс +1 | Счётчик обновляется + мини-анимация |
| Цель выполнена | Зелёная галочка + конфетти |
| Все цели выполнены | Победный джингл → переход |

## ♿ UX правила

1. Тап-область — минимум 80×80px
2. Кнопки неактивны (`interactable = false`) пока анимация попапа не завершена
3. Жизнь тратится только при нажатии «Ещё раз», не при показе экрана поражения
4. Победа без наград = мгновенный переход, не задерживать игрока
5. Выход из уровня через PausePopup — подтверждение («прогресс уровня будет потерян»)
6. `GameLoopController.EnableInput()` вызывается только после закрытия LevelTaskPopup
